# Fókusz

Rövid leírás:

A Fókusz egy olyan applikáció ami próbál segíteni leszokatatni az embereket a telefon függőségről és 
vagy segít diákoknak tabulásra fókuszálni azzal hogy hogy kizárja őket a közösségi média és egyéb telefonos figyelemelterelésektől. 
Jelenlegi állapota szerint kész van a beadásra.
